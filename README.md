## Featured products

### Novasis AI

[Novasis AI](https://novasis.ai) is an AI-assisted operations platform that
brings CRM, project management and finance workflows into one connected system.

Teams can use chat or voice commands to create records, manage customers,
organize projects, assign tasks and monitor financial operations without moving
between disconnected tools.

Key capabilities include:

- AI-assisted CRM and opportunity management;
- project planning and task allocation;
- finance, proposal and invoice tracking;
- text and voice-driven operational actions;
- role-based permissions;
- AI-generated summaries and operational insights;
- unified customer, project and finance data.

### YunCMS

[![npm version](https://img.shields.io/npm/v/%40yunsoft%2Fyuncms?style=flat-square&label=npm)](https://www.npmjs.com/package/@yunsoft/yuncms)
[![License](https://img.shields.io/github/license/Yunsoft-Software/yuncms?style=flat-square)](https://github.com/Yunsoft-Software/yuncms/blob/main/LICENSE)

[YunCMS](https://github.com/Yunsoft-Software/yuncms) is a programmable,
self-hosted MySQL CMS and REST backend with a focused React administration
Studio.

It provides:

- schema-driven collections, fields and relations;
- role-based access control with field and row-level rules;
- REST APIs, authentication and file management;
- local and S3-compatible storage;
- JavaScript extensions and scheduled jobs;
- optional AI assistant and MCP integration;
- backup, restore and managed update commands.

> YunCMS is currently in the documented `0.1.x` pre-stable release line.

- Build around real product requirements.
